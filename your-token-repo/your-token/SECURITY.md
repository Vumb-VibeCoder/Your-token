# Security

The scripts in this repo read `plans.json` and the files you hand them, and write to the ledger (`~/.your-token/ledger.json`) and an optional `--out` file. They make no network calls and start no subprocesses. If you find something that breaks that, it's a bug worth reporting.

To report a problem privately, use the "Report a vulnerability" button under the Security tab of this repo. Please don't open a public issue for it. Only the latest release gets fixes.
